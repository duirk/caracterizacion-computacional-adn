# Caracterización Computacional de Secuencias de ADN

Marco analítico *in silico* para la caracterización de secuencias de ADN mediante:

- Entropía de Shannon
- Contenido GC
- Función hash criptográfica SHA-256
- Control de integridad y trazabilidad digital
- Métrica heurística interna

## Alcance

El modelo es exclusivamente computacional. No pretende demostrar protección física,
estabilidad biológica ni resistencia a la degradación del ADN.
